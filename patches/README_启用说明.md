## 手机 Web 聊天界面

不需要额外开关。浏览器宽度小于等于 `720px` 时自动启用手机布局：

- 召见/外交聊天弹窗会变成接近全屏。
- 输入框固定在底部，发送按钮和底部操作按钮会放大。
- 私聊底部左侧新增 `+` 按钮，点开后显示推荐话术、撤回、退出召对等附加操作。

启用方式：

1. 启动游戏后打开 Web 端页面。
2. 在手机浏览器访问同一个 Web 地址，或在桌面浏览器开发者工具里切到手机尺寸。
3. 进入游戏，打开人物召见聊天，即可看到全屏聊天和底部 `+`。

如果页面已经打开过，修改后请强制刷新一次，避免浏览器缓存旧 JS/CSS。

## LLM 辅助改存档

入口在主菜单：

1. 回到游戏主菜单。
2. 点击 `调试`。
3. 点击 `LLM 辅助改存档`。
4. 左侧复制提示词给 LLM，说清楚你想怎么改。
5. 按 LLM 给出的对象、字段、数值，在右侧作弊器页面执行修改。
6. 修改完成后，回主菜单用 `加载存档` 重新载入对应存档。

如果主菜单没有 `调试` 按钮，说明当前运行状态是 Steam 联机授权模式；原前端会隐藏调试、自定义剧本和 API 设置入口。需要切到非 Steam/API 配置模式，或使用带调试入口的构建。

注意：当前后端包里没有暴露“LLM 对话直接写数据库”的专用接口，所以这里采用安全辅助模式：LLM 负责把自然语言目标拆成改档步骤，实际写库仍由右侧作弊器执行。

## 备份建议

改存档前先在游戏内保存一份备份：

1. 入局后点右上/菜单里的 `游戏菜单`。
2. 选择 `保存存档`。
3. 保存一个新名字。

这样如果改坏了，可以回主菜单重新加载备份。
