`resources/backend/MingSalvageBackend/_internal/content/preset_technologies.json`

## 安装

1. 关闭服务器上的游戏后端进程。
2. 备份服务器原文件：

   `resources/backend/MingSalvageBackend/_internal/content/preset_technologies.json`

3. 将补丁包解压到服务器游戏根目录，保持原目录结构并允许覆盖。
4. 重新启动游戏后端。
5. 重新加载存档；已满足前置条件的下一项科技应出现在科技树中。

Linux 示例：

```bash
cd /服务器上的游戏根目录
cp resources/backend/MingSalvageBackend/_internal/content/preset_technologies.json \
   resources/backend/MingSalvageBackend/_internal/content/preset_technologies.json.bak
tar -xzf 科技线补丁_服务器版_20260624.tar.gz
```

## 已有存档

通常不需要手工修改存档。补丁修改的是预设科技目录；后端重启并重新加载存档后，会按存档中已经研成的科技重新计算可研究项。

只有存档本身缺少一项本应已经研成的前置科技时，才需要使用存档修改器补回该科技。

不要为了“让下一项出现”而把下一项直接改成已研成，否则会跳过正常研发流程；直接写入 `technologies` 表也可能只补了解锁记录，没有补科技结案时应产生的永久修正。

## 回滚

关闭后端，将备份文件恢复为：

`resources/backend/MingSalvageBackend/_internal/content/preset_technologies.json`

然后重新启动后端并重新加载存档。
